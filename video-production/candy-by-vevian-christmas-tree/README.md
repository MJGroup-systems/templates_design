| | |
|---|---|
| פורמט | 1080×1920, 30fps, ‏H.264 + AAC, ‏24 שניות |
| שמע | מוזיקה מקורית (נכתבה בקוד, ללא זכויות יוצרים) – 100BPM, כל חיתוך יושב על תחילת תיבה |
| עוצמה | ‎-14 LUFS (סטנדרט אינסטגרם/טיקטוק) |

## איך זה נבנה

1. **Cloudinary (AI on-the-fly)** – על התמונה המקורית:
   - `e_gen_remove:prompt_business card` – הסרת כרטיס הביקור והשלמת בסיס המרשמלו.
   - `e_background_removal` – חיתוך המוצר; את שאריות קישוטי הנייר ניקינו מקומית (מסכה גאומטרית).
   - הלוח הנקי הועלה מחדש (`candy_tree_clean_plate`) ועליו:
     - `e_upscale/e_background_removal` – חיתוך ‎4x חד (3596×6396) לקלוז-אפים.
     - `c_lpad,w_1100,h_1956,g_south,b_rgb:e8e5e2/e_gen_background_replace:prompt_…/c_lpad,w_1400,h_2489,g_south,b_gen_fill` – שלוש סצנות סטודיו (כהה / שנהב / שולחן חג) עם מרווח לטקסט.
2. **`src/render_text.js` + `src/text.html`** – הכותרות בעברית מרונדרות ב-Chromium (Heebo, Frank Ruhl Libre, Great Vibes) ל-PNG שקופים, כך שה-RTL והניקוד נכונים.
3. **`src/music.py`** – סינתזה של מוזיקת רקע מקורית (קלסטה/תיבת נגינה, פד, פעמוני מזחלת, בס) + אפקטי whoosh ונצנוץ במעברים.
4. **`src/compose.py`** – קומפוזיטור: תנועות מצלמה עם easing, שכבת החיתוך החד מעל הסצנות, בוקה, נצנוצים, Light-sweep על המוצר, אנימציית טקסט (fade + slide + blur), מעברים עם הבזק אור, גריידינג, וינייט וגריין.

## הרצה מחדש

```bash
npm install                      # פונטים (Playwright ו-Chromium נדרשים במכונה)
# הניחו בתיקייה את: p_cut_up.png, ext_dark.png, ext_ivory.png, ext_table.png (מ-Cloudinary)
node src/render_text.js .        # -> text/*.png
python3 src/music.py audio/music.wav
python3 src/compose.py . out/reel.mp4 --audio audio/music.wav
python3 src/compose.py . qa --only 2.0,13.0,22.0   # פריימים בודדים לבדיקה
```

תלויות Python: `numpy`, `Pillow` (עם raqm), `scipy` (לניקוי המסכה), ו-`ffmpeg` עם libx264.
